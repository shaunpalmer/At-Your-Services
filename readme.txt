== Description ==

**At Your Service** is a comprehensive WordPress plugin designed specifically for running service-based businesses. Whether you're a cleaning service, gardener, plumber, electrician, HVAC technician, painter, or contractor, this plugin provides the tools you need to manage your entire operation from within WordPress.

= What is At Your Service For? =

At Your Service is built for **service business owners** who want to:

* Manage customer inquiries and leads
* Track jobs from start to finish
* Create and send professional invoices
* Showcase their services and team
* Build trust with customer reviews
* Organize business content efficiently

Perfect for cleaning services, plumbers, electricians, gardeners, landscapers, HVAC technicians, painters, handyman services, contractors, and any service-based business.

= Core Features =

**Business Management Tools:**

* **Lead Generation** - Professional forms to capture customer inquiries with service selection, contact fields, and responsive design
* **Job Management** - Organize and track jobs through various stages from inquiry to completion
* **Invoicing System** - Create, send, and manage invoices with customer payment tracking and account management
* **Custom Post Types** - Services, Team Members, FAQs, Reviews, and Locations to organize your business content
* **Taxonomies** - Categorize by Service Types, Price Ranges, and Neighbourhoods

**Design & Technical:**

* **WordPress Native Design** - Matches WordPress admin colors for professional, cohesive appearance
* **Modern CSS** - Uses CSS variables (--ays-* namespace) for easy customization
* **No Bootstrap Dependency** - Lightweight custom CSS for better performance
* **Mobile Optimized** - Fully responsive on all devices
* **Translation Ready** - Full internationalization (i18n) support
* **Developer Friendly** - Clean OOP code, proper escaping, WordPress coding standards

= Lead Generation Form =

== Installation ==

= Automatic Installation =

1. Log in to your WordPress dashboard
2. Navigate to Plugins > Add New
3. Search for "At Your Service"
4. Click "Install Now" and then "Activate"

= Manual Installation =

1. Download the plugin zip file
2. Log in to your WordPress dashboard
3. Navigate to Plugins > Add New > Upload Plugin
4. Choose the zip file and click "Install Now"
5. Activate the plugin

= After Activation =

1. You'll see new menu items for Services, Team, FAQs, Reviews, and Locations
2. Start adding your services and team members
3. Use the shortcode `[ays_service_lead]` on any page to display the lead generation form
4. Customize the appearance through your theme's CSS if needed

== Frequently Asked Questions ==

= What features are included in the free version? =

The free version includes 5 custom post types (Services, Team, FAQs, Reviews, Locations), 3 taxonomies, and a lead generation form shortcode. Perfect for showcasing your business and capturing leads.

= Does this work with any theme? =

Yes! At Your Service is designed to work with any properly coded WordPress theme. The styling uses WordPress-native colors and is fully responsive.

= Can I customize the appearance? =

Yes! The plugin uses CSS variables that can be easily customized. You can override the default styles in your theme's CSS file.

= Is this plugin translation ready? =

Yes! At Your Service is fully internationalization (i18n) ready. You can translate it into any language using standard WordPress translation tools.

= What's the difference between free and premium versions? =

The free version focuses on showcasing your services and capturing leads. The premium version adds invoicing, job management, booking systems, CRM features, and more advanced business management tools.

= Does the plugin include invoicing or job management? =

These features are available in the premium version. The free version focuses on service showcase and lead generation.

= Will this slow down my website? =

No! At Your Service is optimized for performance with minimal database queries and efficient code. It only loads scripts and styles where needed.

= Do you offer support? =

Free support is provided through the WordPress.org support forums. Premium users receive priority email support.

= How do I display the lead form? =

Use the shortcode `[ays_service_lead]` on any page or post. You can also add it to widget areas that support shortcodes.

= Can I export my data? =

Yes! All data is stored in standard WordPress custom post types, making it easy to export using WordPress's built-in export tools.

== Privacy Policy ==

At Your Service does not collect, store, or transmit any user data to external servers. All data remains in your WordPress database. The plugin:

* Does not use cookies
* Does not track users
* Does not collect analytics
* Does not transmit data externally
* Stores all data locally in WordPress database

When users submit the lead generation form, their information is stored in your WordPress database only.
